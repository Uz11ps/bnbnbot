# Настройка VK бота

## Добавление токена

Добавьте в файл `.env`:

```
VK_BOT_TOKEN=<ВАШ_VK_ТОКЕН_ГРУППЫ>
```

## Запуск

VK бот запускается автоматически вместе с Telegram ботом через docker-compose:

```bash
docker compose up -d vk_bot
```

Или перезапустить все сервисы:

```bash
docker compose restart
```

## Примечания

- VK бот использует ту же БД, что и Telegram бот
- Пользователи из VK и Telegram разделяются по ID (VK ID обычно положительные, но могут быть отрицательные для групп)
- Клавиатуры VK отличаются от Telegram - используются кнопки вместо inline-кнопок
